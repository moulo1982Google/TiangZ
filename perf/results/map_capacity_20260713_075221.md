## 指标口径

- `MapProbe` 是 ActorLocation RPC，链路为客户端 -> Gate -> MapHost -> Gate -> 客户端，不产生 AOI 广播。
- Map/Gate CPU 使用正式测试窗口内的 5 秒进程 CPU 样本；平均值用于容量判断。
- `push/s` 仍是全地图全量可见广播，代表最坏同屏 O(N^2) 场景。
- Gate 数量用于分摊连接、编码和下行发送；MapHost 始终只有一个。
