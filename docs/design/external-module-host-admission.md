# 外置模块宿主缺口与准入

本次迁移只补充与具体游戏无关的模块装配能力，不改变玩法。

1. 通用领域契约仍从宿主 Model 公共入口提供，不把领域执行器放进 Core。
2. 模块自己生成 System 的稳定方法声明与显式入口。宿主不得扫描另一仓库的内部实现来猜装配。
3. 模块配置允许提供纯校验函数，接收冻结候选与旧表；先验证全部模块、再无回调提交，保留配置事务边界。中立表校验夹具负责回归。
4. Native 模块可显式声明需要宿主资源根初始化；初始化在创建 Process 的线程、V8 启动前执行，不提供任意 Shell 或数据库安装回调。中立 Native 模块夹具验证同一接口。
5. 主工程默认不编入示例 Native op，不安装示例配置和协议；需要这些能力的工程显式声明模块依赖并组合构建。

验收要求：纯宿主构建和计数器 RPC，示例模块类型与完整构建，两个实际消费者的公开依赖及装配验证。协议编号和持久化布局必须保留；真实服务、已有数据库和长稳测试不在本次操作范围。
