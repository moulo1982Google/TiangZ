# 0.7 Host backing store 所有权与观测

2026-09-26：先验证当前锁定的 deno_core 0.411.0 / V8 150.4.0 安全 API，再冻结运行时修改。控制入口数量限制已经完成，本项单独检查实际存活的入站 Host packed 字节，不改变 MMORPG/通用 Core 的边界。

## 首阶段探针

`tests/host_backing_store_ownership.rs` 在独立 Rust 集成测试进程创建真实 JsRuntime；核对现有 Uint8Array 转换与 Rust Box 的地址，使用带 Drop/原子账本的 `Box<T: AsMut<[u8]>>` 转交 V8。验证四字节子视图被闭包持有时仍占整块 65536 字节，显式业务复制不属于原 backing store，最后视图、Native SharedRef 及 isolate 销毁分别控制原所有者释放。强制 GC 仅用于有界测试，不能推导自然 GC 时限，生产暂不加 GC 策略。

当前 feature tree 没有 `v8_enable_sandbox`，证据 `temp/v0.7-host-backing-v8-features.log`。该安全 API 在 sandbox 模式不可用；不自行使用 raw pointer/unsafe 绕过，将来更换 V8 构建模式必须重新评估。

本阶段不承诺进程内存有界，不新增容量默认值。后续若实现观测，仅统计由 Host 实际转交、最后 backing store 所有者尚未释放的整块逻辑字节；入站帧、完成消息混合批次不能只按一个残留视图的长度计费。业务复制、其他 op、字符串/DTO/Component 和分配器开销仍在外。GC 迟延和存活引用都表现为尚未释放，不能看到计数就断言泄漏。

全局硬额度还需要独立冻结完成通道的进展保证、满额时拒绝/暂停位置、已执行业务响应的语义、Native 暂存所有权与 GC 策略。不能让等待中的业务持有满额度，同时把解锁它所需的完成也关在同一额度外；不能用 1011 将已经执行的请求伪装成从未准入。

首轮探针 `temp/v0.7-host-backing-probe-initial.log` 仅编译失败（E0432）：误从 deno_core 根导入 Uint8Array，实际在 convert 模块。按生产 Host 的导入修正；没有执行寿命断言，不计为框架泄漏或 GC 失败。

修正后 Windows 实际 V8 探针 **1/1**、0.03 秒，构建 2.66 秒，`temp/v0.7-host-backing-probe-final.log`。原 Box 地址保持，65536 字节由 4 字节闭包视图继续持有；移除后有界主动 GC 释放一次，独立复制仍可读；Native SharedRef 和 isolate Drop 的最后所有者分别验证。不是自然 GC 的时延测试。

## 第二阶段冻结：观测实际转交的原缓冲区

1. 新增一个 Host 事件缓冲区实现文件，集中放桥接 payload、V8 转换和小型共享原子账本；不拆出纯转发层。ProcessQueueStats 拥有账本，payload 携带原 Arc，不经全局当前 Runtime 查找。原控制名额仍独立转交 OpState。
2. 非空 packed Vec 按既有方式转 Box slice 后转交 V8，仅多一个带 Arc 的所有者盒；不逐帧复制、不改 13 字节头/TS 接口。字节从 V8 转换时开始计，所有 Native/V8 引用中的最后一个释放才减。空 take 不计；未取走的 TLS 批次按原逻辑销毁，不当成已转交。
3. 每 Process 固定标签增加 `tiangz_process_host_backing_store_{bytes,max_bytes,buffers,created_total}`。当前值包含仍可达或尚未被 GC 释放的整块逻辑存储，包括混合批次的帧与 completion；不是按子视图长度累加，不含已转交前 Vec、扩容峰值、分配器、任意业务副本或总堆。
4. Drop 只作原子减计数，没有 TS 回调/await/裸指针或所有权环。保留现有自然 GC，不为指标加主动 GC、阈值拒绝、队列暂停或重试；指标读取是分别采样，不承诺并发字段事务快照。
5. 实际 Process/V8 的原 80×1 MiB 批次用例保留每批小视图，验证跨批次累计高水位和退出后零占用，同时覆盖正常/停机交付；独立 V8 探针、固定标签数值、Windows 含 KCP 完整矩阵、Linux 实际全目标/Clippy及 AI 归档分别验证。两个 VSCode 插件无新配置/语法，不改版本。

这是字节所有权观测阶段；共享字节硬额度仍按上一节单独评审，不能因为新增指标就宣布 N1 内存边界全部完成。
