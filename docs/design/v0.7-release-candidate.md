Host 驻留限额要求 Windows/Linux 真正 V8 与网络矩阵。插件使用实际安装的 VSIX；原生协议测试不能替代 Problems/Hover/Task。AI 客户端存在时使用隔离配置确认实际加载包与只读场景；缺少客户端明确列为未验证，不编造通过。房间、SLG、MMORPG 分别使用同一冻结宿主完成升级和运行；MMORPG 能力继续留在模块，位置服务保持可选。

性能先固定基线、构建参数、负载和容错门槛，再比较同机结果；编译/其他测试与测量阶段错开。长稳按 30、60、120、240、480、960、1440 分钟递增。每一级使用真实单次持续运行、保留请求/错误/延迟/资源/恢复证据；失败时保存证据、修复并重新验证受影响候选，从合适的较短级别重新开始，不能把多个短跑相加当作连续 24 小时。单轮连续 1440 分钟无问题后停止本机长稳；7×24 小时由用户另备环境。

发行准备包含候选包、校验和、升级/回退说明、已知限制、依赖发布顺序与本地提交。不得 push、远程发布、移动历史 tag 或把尚未完成的长稳填写为通过。
