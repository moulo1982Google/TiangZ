# 0.7 本地 Scene 调用准入

本批基于 Actor 验收提交 `3d97aa1`，单独补齐进程内 EntryScene call/send 的队列和在途数量，不搬移 mailbox 执行器，不将网络入站队列/字节总量混入同一契约。

每 EntryScene 最多接受 **4096** 项本地调用，原 ProcessHost 合计 **16384** 项；ordered/unordered、RPC/单向一起计数。沿用已验证的 Actor 候选数量级，限制无限本地排队与多 Scene 绕过局部界限；这不是生产吞吐定容。先验证目标存活，再检查 Scene，最后检查 Process；超限在执行或入队前拒绝 RpcError(SceneOverloaded=1011)。业务公开 call/send 需保留该类型，不在外层变成 SceneCallFailed。一次拒绝只进入一个固定 Process 聚合计数。

单向 send 忙时返回 undefined 仅代表本地当前跳已接受；配额必须附着于实际队列节点，不能放在发送者返回值的 finally 中。快速同步任务结束即释放，异步任务实际结束才释放；销毁目标仅立即终结尚未开始的节点，已开始任务仍占原 Scene/Host 配额。新 Runtime 中同名 Scene 不能被旧回调扣减；本批不新增运行时替换 EntryScene 的 API。同步失败须撤销本次接受且不影响其他调用。Core/Model 形状改变需完整构建重启，不能按 Hotfix-only 投放。

网络入站/Disconnect、Host completion、读取指标和热更控制不使用这份“本地调用”配额，防止满额时又以普通本地调用名额执行释放操作。它们仍遵守各自现有顺序和预算；本批不宣称网络控制积压已有限额。一次本地 Scene 请求再调用 Actor 时会分别持有两层任务名额，指标不将它们相加称为唯一业务请求数。固定 Process 指标区分当前/峰值、两级容量和两级拒绝。

验证先保留旧无上限/公开错误映射的失败反例，再覆盖满额、混合 void/RPC FIFO、实际释放、销毁队列、同号重建和跨 Runtime 回调。真实生成协议验证满额时网络控制仍可完成原任务、Hotfix 仍等待真实收敛、释放后准入与热更恢复；Rust 指标改动重建实际 Host，执行含 KCP 完整矩阵及 Linux 条件编译，AI 指引和实际归档同步。没有新的用户配置、Native 或编译规则，两个 VS Code 插件保留版本与现有 Schema。

## 实现与失败反例

EntryScene 在本地入口接受名额，快速调用交给实际 executeMailboxTask 归还，ordered 排队节点保存归还闭包，由 recycleMailboxTask 在真实完成或未执行即销毁时归还。释放幂等并绑定原 EntryScene/ProcessHost。ProcessRuntime 的热更排空也检查这份 Host 总量。公开 callFrame 保留 RpcError(1011)，不再因本地错误没有 Rust 文本前缀而变为 1006。

首轮反例 `temp/v0.7-local-scene-capacity-first.log` 直接等待旧无界 ordered 队列拒绝，导致首项测试 30 秒超时；这是夹具错误。改为先断言拒绝项没有入队，再等其错误，finally 仍释放 gate，正确 RED 为 `temp/v0.7-local-scene-capacity-red.log` 的 **8 failed**、526ms。接入准入后 `temp/v0.7-local-scene-capacity-propagation-red.log` 为 **7 passed/1 failed**，单独定位公开 call 的 1011→1006 映射缺口。不能加长超时、只测底层 dispatcher 或拼接假 Rust 前缀绕过。

最终定向 **49/49**，`temp/v0.7-local-scene-capacity-focused.log`：本地容量 8 项、mailbox 生命周期 20 项、过载传播 15 项、Actor 容量 6 项。覆盖 ordered RPC/void 混合 FIFO、unordered 两种入口、两级满额/逐项恢复、销毁时保留实际等待、同步编码失败、公开 API 与跨 Runtime 原所有者释放。随后独立类型检查发现夹具 encode 参数被泛型推断为 unknown（TS2345，`temp/v0.7-local-scene-capacity-types.log`）；补显式 Response 参数，`temp/v0.7-local-scene-capacity-types-final.log` 通过。转译测试不能替代类型检查，禁止 as any 绕过。

固定 Process 指标为 `tiangz_local_scene_mailbox_tasks_{in_flight,capacity,per_scene_capacity,max_in_flight,scene_rejected_total,process_rejected_total}`。Rust 保持缺省字段兼容，解析、HTTP 投影与标签用例通过；只统计已接受的本地调用，不将网络、Actor、Spawn 混成唯一业务数。峰值是实际准入峰值，同步业务失败也可能贡献峰值，不等同 Spawn 的注册成功指标。
