# 0.7 共享 Program 契约检查

规则唯一维护在 Developer Tools 的 `runtimeContractRules.ts`（ruleset 1），插件仍沿用 0.15.2 序列。TiangZ 的 `verify_runtime_contracts.mjs` 只创建本次 Program、选择扫描文件、转换退出码并保留 self-test wrapper 检查，不维护第二份生命周期/Timer 规则。模块检查在其已经绑定当前 Core 和生成 System 声明的 Program 上调用相同入口。

作用域按当前宿主的 Core 声明身份判断，支持继承/导入别名/namespace，不凭 `Awake` 或 `NewOnceTimer` 同名断言属于框架。Timer 检查真实接收者，支持类外调用、super、生成增补、重载、可选参数和普通 rest/固定元组；取消上下文只从当前 Core public 导出读取。同名业务接口不能冒充该上下文。Promise 判断要求 then 可调用，避免数值 then DTO 误报。

确定错误使用 `tiangz.lifecycle.async-method`、`tiangz.timer.target-missing`、`tiangz.timer.not-callable`、`tiangz.timer.argument-mismatch`。动态字符串、any/未实例化泛型、无法解析的 receiver/复杂 rest 用 `*.unverifiable` warning，不猜测硬拒绝。动态反射、call/bind 转发、自定义覆盖的工厂不属于完整证明范围，运行时守卫和代码审查继续有效。

主工程编辑器和 CLI 共用一个适配器；LSP 复用最多四个 LanguageService，关闭项目/shutdown dispose。每工程类型缓存限制 10000 文件/128 MiB 源文本，超限显示不可用；这不等同于 TypeScript 堆总内存上限。带版本/哈希的标准库随实际 VSIX 分发。已配置工程缺失类型依赖、配置损坏不能以“零规则错误”冒充完整检查。

独立模块的当前宿主 Program 已接入 CLI、编辑器宿主任务和受信任工作区的实时检查 worker。已保存声明选择宿主；既有模块 TS 的未保存文本只作内存覆盖，关闭恢复磁盘。模块真实路径、联接路径和 Windows 跨盘诊断均由宿主目录身份约束。类型环境不可用不会被当成零错误；不运行生成器或游戏代码，配置未保存须先保存并刷新。容量、进程回收、实际 CLI/LSP 联验范围见[模块实时检查](v0.7-module-live-checks.md)。普通 tsc 不会自动执行这些自定义规则，CI 继续调用版本化本地检查入口。

验证证据：

- Developer Tools Core 正反例涵盖无关同名类、旧宿主、别名/接口、推导 Promise、普通 then DTO、实际 receiver、重载/rest/optional、生成声明、取消上下文、动态警告和 options 覆盖次序。
- 实际 CLI 与 bundled LSP 对同一工程逐项比较诊断；未保存修复后清空错误，关闭项目后类型缓存归零。
- 宿主 TS 6.0.3 自测使用真实 Core；外置模块测试排除无效旧宿主 d.ts，保留本地声明、纳入当前模块 System 声明；确定错误退出 1，纯动态 warning 退出 0 并保留 JSON 诊断。
- 首次 LSP 集成用例误把 indexFiles 参数发成 JSON-RPC positional 数组，修正为生产使用的 `{ roots: [...] }`；清理夹具时使用已有 dispose/shutdown API，不留测试子进程。未降低诊断或缓存释放断言。
- Developer Tools 全套 133 条通过；最终 VSIX 标准库/两个 bundle 哈希与实际安装内容一致，从已安装服务执行同一真实 LSP 用例通过。版本与归档 SHA 见[插件记录](v0.7-plugin-compatibility.md)。

当前通过显式本地 npm 包联调；发布依赖还指向原 tag/main。默认依赖冻结、干净检出复验仍是发布门槛，不能把本地候选安装等同于已发布版本。最终日志和提交见[实施进度](v0.7-progress.md)。

整轮接线验证 check 8/8、quick 32/32、full 7/8，唯一失败是热更故障矩阵首次 admin 连接的 Windows ENOBUFS。原三轮复测通过、正常回收测试宿主，未修改生产配置或降低 500 连接负载；不能依据事后端口/内存采样确定该次系统资源失败的根因。最终候选又完成 check 8/8、重载实现与当前宿主模块定向检查，原始失败保留。
