# 0.7 Scene Spawn 准入失败的原子性

2026-09-26 实施前冻结。沿用 Scene 任务真实在途/析构契约，先修复失败准入会残留计数的路径，为后续共享额度提供可靠释放点。本步不新增任务额度或公开配置。

`Tasks.Spawn` 返回 ID 才表示任务已接受；名称/body/容量校验或 watchdog 注册同步失败时，原异常仍向调用方抛出，任务 body 不执行，也不能留下 task record、在途数、成功高水位或不属于已注册 Timer 的 owner 引用。ID 可以跳号，不回退计数器或复用尚可能出现的 ID。

watchdog 仍为 Scene 所有，创建成功后才保存原 TimerSystem 实例和句柄。其他 Scene 的任务和计时器不受一次失败影响；已接受的异步任务继续保持额度/热更计数到真实结束，Dispose/取消不能提前归还。此处不能用吞掉 Timer 错误、关闭 watchdog 或清空全部任务来恢复。

验收覆盖实际服务缺失、Timer 注册失败、同一 Scope 重试恢复、其他 Scope 的真实在途任务/Timer 保持，以及真实 V8 请求已返回后热更能够正常排空。失败用例先于实现运行，两份 AI 开发入口与分发规则同步，按生命周期变更执行完整矩阵。
