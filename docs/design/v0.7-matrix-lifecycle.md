2026-09-26 实施前冻结，落实总设计第 11 章。已有 feature 传递和实际宿主身份记录保留。

每个步骤有独立墙钟期限：普通检查/短测 5 分钟，Rust build/clippy/test 与 Native 构建 30 分钟，嵌套 check 30 分钟，嵌套 quick 90 分钟。它们是验收工具防挂起阈值，非性能指标；默认保留冷构建余量。`TIANGZ_VERIFY_TIMEOUT_SCALE` 允许 0.1..100 的有限倍率，0 不表示无限。计划和 JSON 显示具体毫秒，环境传递到嵌套矩阵。

运行器用异步子进程等待，保留失败后继续后续步骤。超时只有在所属进程树已回收后才能继续。Windows 使用独立 Job Object，创建目标进程时先挂入 job 再恢复线程；job 关闭会终结其后代，避免只 taskkill 一个已退出 PID。辅助 PowerShell 只执行随仓库的固定脚本，程序与参数作为数据传递，隐藏窗口、不运行 shell 拼接命令。无法建立所有权即失败，不降级成无界启动。Unix 使用每步独立进程组，超时/中止按组终结。故意脱离进程组或向外部已有服务提交任务不在此工具的取消证明范围。

Windows 实现核对了微软的 [Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects) 与 [CreateProcessW](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessw) 契约：job 句柄不继承，设置 KILL_ON_JOB_CLOSE，暂停创建后 assign 再 resume；继承的标准流保持原输出路径。正常退出若仍有后代，关闭 job 并将原成功改为退出码 125。通过外部服务/WMI 创建的独立任务不属于这个后代约束。

Unix 的进程组还需要父级消失通路：嵌套矩阵会创建新的组，仅杀外层组不能保证全部结束。专用 Node 组拥有者保持轻量事件循环，IPC EOF 即终结本组，支持层层回收；不能把这份职责留给可能同步阻塞的被测命令。Linux 用 procfs 确认组内活动后代，非 Linux 的 ps 后备路径尚需在对应系统另验。

SIGINT/SIGTERM 中止整轮：当前步骤标记 aborted，后续标记 skipped，仍写 JSON/JUnit，退出非零。超时为 timed-out 并计失败，不改记测试通过。正常命令退出后仍遗留的所属后代须回收；不得让一步的服务污染下一步。不得因清理测试进程操作用户既有数据库或外部服务。

CI 捕获输出采用有限缓冲并明确截断，保留末尾错误；本机继续继承终端。失败日志与注解和现有报告路径兼容，记录期限、退出码、状态及回收问题。新执行器按职责单独成文件，不借此重写检查清单。

每步 CI 输出最多保留 4 MiB，使用固定头部/尾部缓冲而不是无限 chunk 数组，防止小片段元数据绕过字节限额。失败后保留错误末尾并写既有日志/注解。回收另有 5 秒期限，若未完成则明确 cleanupFailed 并中止后续步骤，不能在未知进程残留时继续宣布独立验证。

验证包括原失败后继续夹具、挂起子孙进程和实际 TCP 端口回收、中止后跳过/报告、未能 spawn、输出超限、默认/feature/倍率计划。Windows 必须实际运行 Job 路径；Unix 另行隔离验证进程组，不能以 Windows 结果代替。最后跑当前矩阵验证普通成功路径。
